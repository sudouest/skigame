# `skigame` Project Knowledge Base

`skigame` is an endless 3rd-person cartoon downhill skiing game built with **TypeScript**, **Three.js (`^0.181.0`)**, **Vite (`^7.2.0`)**, and **Vitest (`^4.0.0`)**. A strictly headless 60 Hz simulation (`src/sim/`) runs True-3D ski physics (`SkiDynamics` + quarantined Jolt Physics WASM) in authoritative right-handed **World Space `(X, Y, Z)`** (`+Y` up, `-Z` forward) over a continuous procedural heightfield (`MountainField`) backed by a 4-slot sliding `TrailWindow` with Model A trail forks, Tier-1/Tier-2 horizon lookahead, ghost elevation history, and 128 m translation-only floating-origin rebasing. A pooled cel-shaded 3D + 2.5D cylindrical billboard renderer (`src/render/three/`) drives a 1-draw-call `0.5 m` instanced CDLOD clipmap (`ClipmapDataStore` + `TerrainClipmap`) and decoupled `32 m` `SceneryCellStreamer` within a 5 ms frame budget and enforces reference-counted GPU resource tracking via `GraphicsTracker` / `GraphicsUtils`.

## Build, Typecheck & Test Commands

```bash
npm run dev        # Start Vite dev server (base: '/skigame/')
npm run build      # Production static bundle -> dist/
npm run preview    # Preview production bundle
npm run typecheck  # Strict TypeScript check (tsc --noEmit)
npm run test       # Watch mode Vitest (Node environment)
npm run test:run   # Run full headless Vitest suite (23 test files, 112 tests, includes 50 km soak)
```

## Top 10 Load-Bearing Invariants & Footguns

1. **Strict Headless Layering & Zero Singletons (`src/core/architecture.test.ts:146-220`)** — `src/core/`, `src/content/`, and `src/sim/` MUST NEVER import `three` or reference DOM globals (`window`, `document`, `HTMLElement`, `requestAnimationFrame`, `cancelAnimationFrame` — even via `globalThis`/`self`). Defining `getInstance` anywhere in `src/` fails tests. `src/ui/` may only import `../sim/contracts` from `sim` and never `three` or `render/` (`src/ui/__tests__/uiFormatting.test.ts:302-328`).
2. **Mandatory `GraphicsUtils` Factory & GPU Tracking (`src/render/three/__tests__/graphicsTracker.test.ts:161-176`)** — Never write `new THREE.Mesh`, `new THREE.InstancedMesh`, `new THREE.Line`, `new THREE.LineSegments`, `new THREE.LineLoop`, or `new THREE.Points` in `src/render/three/` outside `graphicsUtils.ts`. Always register/dispose via `GraphicsUtils`, mark shared assets with `markAsCache`, and keep `checkLeaks(20, true, scene)` at 0 leaks.
3. **128 m Translation-Only Floating-Origin Rebase (`src/sim/skiSimulation.ts:47, 649-655, 1080-1123`, `clipmapDataStore.ts`)** — Whenever `|posX|`, `|posY|`, or `|posZ| >= 128`, the world translates by `(dx, dy, dz)` and emits `WORLD_REBASED`. Terrain noise MUST evaluate in absolute coordinates `(wx + originOffsetX, wz + originOffsetZ)`, `ClipmapDataStore` performs **zero texel re-evaluations and zero GPU uploads** across fractional rebases (via exact `float64`-modulo `uLayerOriginModXZ`), and `SceneryCellStreamer` / `LandmarkStreamer` translate origins only.
4. **Zero Heap Allocations in Hot Loops** — Inside `SkiSimulation.step()` (60 Hz), `ThreeRenderer.sync()` (60–144 Hz), and `GameUI.update()`, allocate zero objects/arrays/closures/DOM nodes. Reuse module-private scratch objects (`_mat4`, `_pos`, `scratchFrame`, pre-allocated `EventBus` payloads) and dirty-check DOM updates.
5. **Packed `InstancedMesh` with `frustumCulled = false`** — Every streaming `InstancedMesh` must pack active instances contiguously `[0, count)` and disable `frustumCulled` (`graphicsUtils.ts:51`) because Three.js culls against the base geometry's local origin bounding sphere, not live instance matrices.
6. **Spline Non-Self-Intersection & Downhill Cone (`src/sim/trailSpine.ts:20-33, 338-339`)** — Every spine strictly enforces `|k(s)| * (halfWidth + skirtWidth) <= 0.395` (`<= 0.4` tested), `|yawRad| <= 60°` (`<= 48°` at fork seams), and flat fork seams (`k = 0, bank = 0` at `s = 0` and `s = length`). Never use Frenet-Serret frames.
7. **50 km Headless Soak Contract (`src/sim/__tests__/soak50km.test.ts:9-243`)** — `npm run test:run` (`23/23` files, `112/112` tests, `~18.15–18.48 s` baseline) steps up to `180,000` ticks (`50+ km`, `100+` forks, `200+` rebases, all 5 stages) inside a **20 s timeout** in Node — `soak50km.test.ts` runs in **`~15.27–15.99 s` under 23-file parallel load**, leaving ~4–4.7 s of headroom. Any per-tick physics/terrain/WASM overhead or unbounded pool/ghost growth breaks this gate.
8. **Cartoon Color & Fog Floor Rules (`src/render/three/renderer.ts:189-190`, `toonMaterials.ts:74-109`, `snowVfx.ts:13`)** — Use `SRGBColorSpace` + `NoToneMapping` (never `ACESFilmicToneMapping`), a single cached `3×1` `NearestFilter` `NoColorSpace` toon `gradientMap`, explicit `linearToSRGBChannel` encoding on `SRGB8_ALPHA8` `ClipmapDataStore.albedoTex`, and keep `FogExp2` distance clamped `>= 65 m`.
9. **Unified `MountainField` Height Parity (`layoutEngine.ts:413-445`, `sceneryCellStreamer.ts`)** — `LayoutEngine.samplePlacementSurface` now queries `MountainField.evaluate(wx, wz)` directly (and `SceneryCellStreamer` queries `TerrainFieldView`), eliminating the legacy `3.6 m` `segment.evaluateSurfaceAtX()` snowbank discrepancy (`3.7e-4 m` parity). Never use `evaluateSurfaceAtX()` for terrain/prop parity, and always keep `ClipmapDataStore` (`needsUpdate = true` before `initTexture`) and `TerrainClipmap` (`effectiveRanges` / non-overlapping `CLIPMAP_MORPH_STARTS_M`) synchronized.
10. **`DESIGN.md` vs. Implemented Reality** — `DESIGN.md` includes Phase 2–3 aspirational items that do **not** exist in the repo yet (no `.glb` models, `public/assets/`, `stage-designer.html`, `asset-inspector.html`, `src/tools/`, audio engine, Capacitor wrapper, or Ogre/Yeti implementations). Always trust the code and this KB over `DESIGN.md` for current state.
